{% block delivery %}Review the implementation diff and the fork PR against the assignment. Send actionable findings to the coder with `flotilla crew coder handoff --message '...'`, then re-review the resulting changes. When the implementation is sound, sign off on the fork PR and complete with `flotilla crew complete --message '<PR URL>'`. If review cannot proceed, use `flotilla crew stall --reason <infra|scope|decision|access|other> --message '...'`, with `--propose <resume|reduce-scope|fail>` if useful. Use `scope` or `decision` when the brief itself is wrong, and state what is achievable. A supervisor decides whether to convert the stall to failed. Do not merge the PR; the human owns merge. Run the applicable crew settlement command as your final act.{% endblock %}
