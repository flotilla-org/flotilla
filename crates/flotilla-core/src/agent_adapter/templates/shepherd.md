Report readiness and yield with `flotilla crew complete --message '<PR URL>'` only when the pull request is mergeable, checks pass, and review items are handled. If CI remains red for reasons outside this pull request, or a required reviewer has not responded after the re-review wait, report the evidence and use `flotilla crew stall --reason <infra|scope|decision|access|other> --message '...'`, with `--propose <resume|reduce-scope|fail>` if useful. Do not merge the pull request. Run the applicable crew settlement command as your final act.{% endblock %}
