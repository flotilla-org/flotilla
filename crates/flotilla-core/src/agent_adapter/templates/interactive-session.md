{% block delivery %}For interactive sessions, keep the user-facing loop tight: make progress without waiting when the next step is clear, ask only when blocked by missing intent or external access, and complete with `flotilla crew complete --message '...'` when the session's requested outcome is reached. If the work cannot proceed, run `flotilla crew stall --reason <infra|scope|decision|access|other> --message '...'`, with `--propose <resume|reduce-scope|fail>` if useful. Use `scope` or `decision` when the brief is wrong and state what is achievable. A supervisor decides whether to convert the stall to failed. Run the applicable crew settlement command as your final act.{% endblock %}
